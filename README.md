# Aethon

Aethon is a C++ framework for decoding, validating, replaying, routing, and analyzing binary telemetry streams generated by distributed RF sensor networks.

The codebase is organized as a reusable library with operational tools for live collectors, offline archive inspection, replay, fuzzing, and diagnostics.

## Build

```sh
cmake -S . -B build
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

The default build uses only the C++ standard library and does not fetch dependencies.
